# Cosmic Field Guide - Project Plan

## Project Overview

The Cosmic Field Guide is a multi-page educational website designed to explore planets, galaxies, and major space missions through an interactive and visually
engaging experience. The purpose of this project is to demonstrate foundational web development skills while applying project management principles from "Project Management for the Unofficial Project Manager" (PMUPM).

The website was built using HTML5, CSS3, GitHub, GitHub Pages, and Visual Studio Code. The final product includes responsive layouts, reusable card systems, expandable information panels, custom styling, animations, and organized navigation across multiple pages. 


# Project Objectives

## Primary Goals

* Build a professional multi-page website
* Create a consistent visual design across all pages
* Demonstrate understanding of HTML and CSS fundamentals
* Practice GitHub version control and deployment workflows
* Apply project planning and risk management concepts
* Develop a portfolio-ready web project

# Work Breakdown Structure (WBS)

* Create a project scope statement

### Galaxies Page

### Missions Page

# Phase 3 - Testing and Deployment

* Test navigation links
* Fix formatting and spacing issues
* Verify image paths and responsiveness
* Push updates through GitHub Desktop
* Deploy website using GitHub Pages
* Perform final review and cleanup

# TAME Risk Analysis

| Risk | Type | Impact | Mitigation |

|------|------|------|------|

| Broken navigation links | Technical | Pages may not load correctly | Test all navigation links frequently |

| Incorrect image file paths | Technical | Images may fail to display | Keep images organized in a dedicated folder |

| CSS formatting inconsistencies | Managerial | Pages may appear visually inconsistent | Reuse common CSS classes across all pages |

| GitHub deployment issues | External | Live website may not update properly | Push commits regularly and verify deployment |

| Scope expansion | Managerial | Project could become overwhelming | Focus on completing core requirements first |
