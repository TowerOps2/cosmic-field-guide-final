# Cosmic Field Guide

## Project Overview

Cosmic Field Guide is a multi-page educational website focused on planets, galaxies, and space missions. The project was designed to combine modern frontend design principles with project management concepts learned throughout the course. 

The website includes: 
* Responsive layouts
* Interactive expandable cards
* Animated backgrounds and hover effects
* Multi-page navigation
* Space-themed visual design
* GitHub Pages deployment
