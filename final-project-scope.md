# Project Scope Statement
## Cosmic Field Guide Website

### Project Purpose
The purpose of this project is to design and develop a professional, informational website about space using HTML and CSS. The project will demostrate foundational web development skills and the ability to manage a project from planning to deployment

### Project Description
This project involves creating a static website that provides educational content about space, including planets, deep space objects, and space exploration. The website will consist of mulitple linked pages, a consistent navigation system, and a engaging visual design. The final product will be hosted pubilicly using GitHub Pages. 

### Desired Results
* A fully functional website
* Clean and consistent structure and design
* Working navigation to linked websites
* Proper file structure and organization
* A live, publicly accessible website via GitHub Pages
* A professional GitHub repository with clear commits

### Exclusions
* No JavaScript or dynamic functionality
* No backend system or database
* No user authentication or login features
* No real time data integrations
